Web Development Basics

What is HTML?

HTML gives a web page its structure. It uses tags to mark headings, paragraphs, lists, and links.

every page you visit is built on HTML, even if it looks very fancy

What is CSS?

CSS controls how the HTML looks. It handles colors, fonts, spacing, and layout.

  • HTML builds the structure
  • CSS styles the pages
  • JavaScript adds behavior
